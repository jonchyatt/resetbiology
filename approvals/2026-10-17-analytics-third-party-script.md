Only if you want more than server-log counts. The analytics loop (docs/ANALYTICS-LOOP.md) needs no new vendor: it tallies store_click and tool_view lines from exported host logs. A script such as Plausible or Google Analytics would send visitor data to a third party, which is red 5. Built up to the line: event spec, tally script, synthetic test. On yes, name the tool and a thread adds the script behind a flag, off until you flip it. On no, nothing changes and the log tally stays the loop.
